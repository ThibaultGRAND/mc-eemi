# Sources (recherche du 16/11/2026)

Aucune guideline officielle de la Build Team Hypixel n'est publique. Les chiffres « [synthèse] » sont à valider en jeu.

## Skills existants (lus, rien installé)

| Skill | Licence | Verdict |
|---|---|---|
| Vibecraft (amenti-labs) — https://github.com/amenti-labs/vibecraft | MIT | Référence utile : échelle, palettes, formules de formes. Dépend d'un MCP Python + mod Fabric ; bruit de hachage non lissé (à remplacer par simplex). |
| Schematica — https://skills.cat/skills/tester2024/schematica | non affichée | Idée d'architecture (primitives + booléens + déformation par bruit), aucune règle esthétique. |
| minecraft-world-generation (Jahrome907) — https://claudskills.com/skills/minecraft-world-generation/ | MIT | Hors sujet (worldgen par datapack). |
| chapmanjw/minecraft-java-fabric-claude-plugin — https://cdn.jsdelivr.net/gh/chapmanjw/minecraft-java-fabric-claude-plugin@main/README.md | MIT | Le plus utile : seuils de qualité mesurables (`reference/terrain/non-negotiables.md`), palettes chiffrées, façade en 3 couches. |
